# Research

- Infinix official ZERO BOOK 13 specifications confirm a fingerprint sensor.
- Public Windows driver inventories for ZERO BOOK 13 identify ACPI\\VEN_FTE&DEV_4800 as FocalTech Fingerprint reader.
- Existing community Linux work provides FTE4800 SPI DKMS + libfprint support for some systems.
- Upstream libfprint supported-device documentation does not currently list FTE4800 SPI.
